# MUSQUEN

High-Performance Brand Acceleration & Immersive Web Platform for **Musquen Media**.

## 🚀 Tech Stack
- **Framework:** Next.js 16 (App Router)
- **3D Graphics & Geodesics:** Three.js Relativistic Schwarzschild Ray-Marching Shader (60+ FPS Hardware Bilinear Scaling)
- **Animations & Physics:** GSAP (GreenSock) + `@gsap/react` + Lenis Smooth Scroll
- **Design & Styling:** Tailwind CSS + Apple Liquid Glass UI + Lucide Icons

## 🛠️ Getting Started
Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
